How to Change a Voucher Number in TallyPrime

Most people who want to know how to change a voucher number in TallyPrime have a concrete problem. A sales invoice went out with the wrong number. A payment voucher needs to follow an outside reference. Or the series has to restart for a new financial year or a new branch.

This page is that how-to. It is not a full tour of every numbering method. For automatic, manual and multi-user methods, prefix rules and why gaps cause trouble, see TallyPrime flexible voucher numbering.

What “change a voucher number” actually means

These are different jobs, and mixing them up is how a tidy company file gets messy:

  • Change the numbering method on the voucher type, so new entries follow a different rule
  • Change the prefix, suffix, restart date or width, so the next invoice looks like INV/001/26-27 instead of 1
  • Change the number on one voucher that has already been saved

A method change affects what TallyPrime offers next. Editing one saved voucher only fixes that entry, and only if the voucher type allows a manual number. Neither step rewrites invoices you have already printed or emailed.

How to change the numbering rule on a voucher type

The numbering rule lives on the voucher type, not on a hidden company switch. The usual path is:

  1. Go to Gateway of Tally > Alter > Voucher Type, then open the type you want — Sales, Purchase, Receipt, Payment or another type you actually use
  2. Find Method of Voucher Numbering and choose the rule you need: automatic, automatic with manual override, or manual
  3. Review the controls next to it: prevent duplicates, restart numbering, prefix, suffix, width of the numerical part, and whether the original number is kept after a deletion
  4. Save the voucher type, then make one or two sample entries and look at the print, the report and the next number TallyPrime offers

If the team types a lot of entries by hand and numbers drift, look at Tally data entry automation as well as the numbering rule. A cleaner method will not help if every number is still being typed over.

How to change the number on one saved voucher

Open the voucher in alteration. If the method is manual, or automatic with manual override, you can usually edit the number, then save. If the method is plain automatic, TallyPrime may not let you type a different number until the voucher type is changed.

Before you save a new number on a voucher that has already been printed, shared with a customer, or included in a GST report, stop and check the old number is not still sitting on a document outside TallyPrime. Reusing a cancelled or deleted number is a common source of later questions. Where the voucher type allows it, keep the original number and mark the voucher cancelled, rather than shuffling the rest of the series.

If several people type entries at once, switch the method first, then test. Do not start by editing old numbers one by one.

Checks before you change live numbers

  1. Take a backup, so you can restore the company if the new rule does not behave as you expected
  2. List any invoices already printed or emailed in the series you are about to change
  3. After the change, review the sales register and the GST reports for the same period
  4. If you are changing the method or the restart date, test in a copy company before the live file
  5. Turn on duplicate prevention, especially if anyone can override a number
  6. Decide who is allowed to edit a number, and write down what each prefix or branch code means

Once the series is stable, period-end work — including the figures that later support ITR filing with TallyPrime — is easier to stand behind, because the documents and the books still agree.

Conclusion

Changing a voucher number in TallyPrime is either a voucher type change, or an edit to one saved entry. Treat them separately, test a sample, and do not alter a number that has already gone out on a tax invoice unless you know how that document will be corrected. FAQs on changing a voucher number in TallyPrime

1. Can I change a voucher number after the entry is saved?

Yes, if the voucher type uses manual numbering or automatic numbering with manual override. Open the voucher in alteration, edit the number and save. Plain automatic numbering may not allow the edit until you change the method.

2. How do I restart voucher numbers for a new financial year?

On the voucher type, use restart numbering and set the date from which the sequence should begin again. Many Indian businesses use 1 April. Test the first invoice of the new year before the team continues.

3. Can TallyPrime stop duplicate voucher numbers?

Yes. Enable duplicate prevention on the voucher type, especially when numbers can be typed or overridden.

4. Should I reuse a number after a voucher is deleted?

It is usually safer to keep the original number and mark the voucher cancelled, rather than close the gap and reuse the number on a new document.

5. When is customisation needed?

When one voucher type needs a rule TallyPrime does not offer on that screen — for example a series driven by branch, channel or an outside system. That is customisation work, not just a setting change.
